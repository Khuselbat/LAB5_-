# (Лекцийн сэдэв) Өгөгдлийн сангийн удирдлагын бичиг баримт болон нууц үгийн бодлогыг хэрэгжүүлэх

## (Асуулт) 
### Өгөгдлийн сангийн удирдлагын баримт бичиг гэж юу вэ? Байгууллагад яагаад зайлшгүй шаардлагатай болохыг тайлбарлаж, бодит жишээ дурдана уу.

## (Хариулт) 
### Өгөгдлийн сангийн удирдлагын баримт бичиг гэдэг нь байгуулгын өгөгдлийн сан (Databse System)-г аюулгүй, найдвартай, тогтвортой ажиллуулах зорилгоор боловсруулсан албан ёсны дүрэм, журам, заавар, стандартуудын цогц юм.
### Эдгээр баримт бичигүүд нь:
* Хэн ямар эрхтэй хандах вэ?
* Ямар мэдээлэл нууцлах вэ?
* Системийг хэрхэн хамгаалах вэ?
* Асуудал гарвал яаж шийдвэрлэх вэ?
### Өөрөөр хэлбэл:
**Техникийн хамгаалалт + Зохион байгуулалтын журам = Мэдээлэлийн аюулүй байдал**
### Яагаад зайлшгүй хэрэгтэй вэ
1. **Өгөгдлийн аюулгүй байдлыг хангана**

Баримт бичигтэй бол мэдээллийг хэн ашиглах, ямар нөхцөлд өөрчлөхийг тодорхой болгодог. Ингэснээр мэдээлэл алдагдах, буруу ашиглагдах эрсдэл багасна.

2. **Ажилтнуудын ойлголтыг нэг мөр болгоно**

Шинэ ажилтан ирэхэд системийг ойлгоход амар болдог. Учир нь бүх дүрэм, бүтэц нь баримтжсан байдаг.

3. **Системийн засвар, хөгжүүлэлтийг хялбар болгоно**

IT инженер системд өөрчлөлт хийх үед өгөгдлийн бүтэц, холбоосыг баримт бичгээс хараад хурдан ойлгох боломжтой.

4. **Алдаа гарсан үед сэргээхэд тусална**

Backup болон recovery-ийн заавар бичигдсэн байдаг тул өгөгдөл устсан эсвэл систем доголдсон үед хурдан сэргээж чадна.
## (Жишээ) 

### Банкны байгууллага клиентүүдийн мэдээллийг хадгалдаг. Үүнд:

* Харилцагчийн нэр

* Дансны дугаар

* Гүйлгээний түүх

* Зээлийн мэдээлэл

### Хэрэв өгөгдлийн сангийн удирдлагын баримт бичиг байхгүй бол:

* Хэн ч дур мэдэн мэдээлэл өөрчилж болзошгүй

* Системийн бүтэц ойлгомжгүй болно

* Алдаа гарвал мэдээллийг сэргээхэд хэцүү болно

### Харин баримт бичигтэй бол:

* Зөвхөн эрхтэй ажилтан мэдээлэлд нэвтрэх

* Гүйлгээний мэдээлэл тогтмол нөөцлөгдөх

* систем доголдвол сэргээх тодорхой журам ашиглах боломжтой.
## (Дүгнэлт)
### Товчхондоо, өгөгдлийн сангийн удирдлагын баримт бичиг нь байгууллагын мэдээллийг **зөв, эмх цэгцтэй, аюулгүй хадгалах “заавар”** гэсэн үг юм. Хэрхэн хадгалах, хэн ашиглах, алдаа гарвал яаж засах зэрэг бүх зүйл тодорхой бичигдсэн байдаг. Ийм баримт бичигтэй бол ажилтнууд мэдээллийг зөв ашиглаж, систем доголдсон үед хурдан шийдвэрлэх боломжтой болдог. Тиймээс байгууллагын мэдээллийг **найдвартай хамгаалах, тогтвортой ажиллуулахад** энэ баримт бичиг маш чухал байдаг.
